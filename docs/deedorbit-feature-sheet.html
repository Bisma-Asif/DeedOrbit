Deed•Orbit
Real Estate ERP
All-in-one platform
Property business ka poora kaam — projects, booking, payments, documents, construction aur accounts — ek secure system mein. Alag-alag Excel files aur WhatsApp groups ki zaroorat khatam.
Live demo: https://deedorbit.vercel.app  ·  Har company ka apna alag khana (multi-tenant) — data aapas mein nahi milta.
Kiske liye

Developers, plot-schemes / housing societies, property dealers aur construction companies — jinke paas units, customers, installments aur vendors ka hisaab barqarar rakhna mushkil ho raha hai.

Module-wise Demo Flow

Ek bilkul naye tenant par chal-te hue ka step-by-step rasta. Demo ke liye naya workspace sign-up se banayein.

  1. Account / Login
    • deedorbit.vercel.app par Create workspace se naya tenant (aap Tenant Owner ban jate ho), ya Sign in.
    • Pehli baar 2FA on kar sakte ho (Settings → Security).
  2. Pehla Project & Units
    • Projects → New Project (naam, location).
    • Project khol kar Structure mein blocks/phases.
    • Inventory / Units → units add (ya CSV import): type, Marla size, price, Status.
    Available status hi agla gate hai — sirf available unit book hota hai.
  3. Lead → Customer
    • Leads → New Lead (naam, phone, source).
    • Pipeline stage move karein (Contacted → Interested → …) jab tak Converted — conversion se Customer profile ban jata hai.
  4. Quotation → Booking
    • Quotations → customer → unit select → price/discount → Save / Issue.
    • Quote se Create Booking → Payment Plan: total, down-payment, installments, due dates.
    • Booking confirm hone par unit Booked ho jata hai.
    Agar documents pending hon to booking ruk sakti hai — dekhhein step 6.
  5. Payments & Collections
    • Booking khol kar Record Payment (amount, mode, date).
    • System Receipt + customer Ledger entry banata hai — Paid / Outstanding khud update.
    • Due nikal gayi to Late Fees rule ke hisaab se (Settings → Late Fees / Cancellation).
    • Collections screen par saare dues, CSV export ke saath.
  6. Refund / Cancellation (Approval ke saath)
    • Refunds ya Transfers/Cancellation request banayein.
    • Seedha apply nahi hota — Approvals mein jata hai.
    • Doosra authorized user Approve/Reject (reason ke saath) → ledger adjust.
  7. Documents & Verification (safety net)
    • Documents → customer ke liye CNIC upload.
    • File encrypt hoti hai, CNIC OCR value nikalti hai, duplicate check hota hai.
    • Verification Queue → Verify / Reject.
    • Expiry alerts (60/30/7 din pehle) + auto reminders.
    • Emergency mein Override — jo log ho jata hai. Sensitive data masked; reveal/download par audit entry.
    Rule: verify na hone tak booking block — fraud/ duplicate rokne ke liye.
  8. Customer Portal
    • Booking screen se portal link bhejein → customer apni booking, payments, receipts, documents khud dekhta hai.
  9. Construction & Procurement
    • Construction → contractors, phases, tasks, site progress logs.
    • Procurement → Material Requisition → Purchase Order → GRN → Stock (PO/expense approvals se jate hain).
  10. Expenses, Vendors & Accounting
    • Vendors + contracts/invoices; Expenses (attachments ke saath) → approval → vendor ledger + journal.
    • Chart of Accounts setup; transactions se Journal entries; Month-closing se period lock.
  11. Reminders, Campaigns & Notifications
    • Communications → SMS/WhatsApp/email Templates; Campaigns; payment/document-expiry Reminders auto-scheduled.
  12. Dashboard, Reports & Assistant
    • Dashboard = sales, collections, dues, occupancy ek nazar.
    • Reports = detailed numbers, CSV/Excel export · Ask-DeedOrbit = sawal ka jawab data se.
  13. Team & Security
    • Users → staff add; Roles/Permissions se har koi sirf apna kaam dekhe; branch-wise access.
    • Audit Log = sab changes ki history.
